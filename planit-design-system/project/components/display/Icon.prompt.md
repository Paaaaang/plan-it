Lucide glyph wrapper. Outline set, 1.5–1.75px stroke, inherits `currentColor` (never inject color directly). The page must load the Lucide UMD script (`<script src="https://unpkg.com/lucide@latest"></script>`).

```jsx
<Icon name="map-pin" size={24} />
<Icon name="share-2" color="var(--text-brand)" />
```

Common Planit names: `calendar`, `map-pin`, `clock`, `share-2`, `link`, `copy`, `chevron-right`, `plus`, `sparkles`, `bus`, `navigation`, `users`, `bar-chart-3`, `settings`, `bell`, `search`, `grip-vertical`, `eye`.
